# Engine card skill

Everything an agent needs to write an engine card for XLM Studio, from a request
such as "make a card for this engine (GitHub link) for XLM Studio (GitHub link)".

| File | What it is |
|---|---|
| `../engine-cards.md` | The guide: the full card format. |
| `SKILL.md` | The instructions for the agent. XLM Studio writes it, with the guide, the checker and the examples, to `~/.agents/skills/xlm-studio-engine-card/` (Settings > Engine Cards > Add SKILL). |
| `check-card.cjs` | The checker. Dependency-free; generated by `node scripts/build-card-check.js` from `src/tools/checkCard.ts`, so it always runs the app's own validation. |
| `examples/` | A complete engine card and a fork card. |

An agent without the skill installed can read `SKILL.md` and `../engine-cards.md`
straight from the repository and download `check-card.cjs` from it.

When the card format changes: update the guide, rebuild the checker
(`node scripts/build-card-check.js`) and commit the result. `node scripts/card-skill-verify.js`
fails when the checker or the examples are out of date.

The card tests planned for this folder will go here, next to the guide.
